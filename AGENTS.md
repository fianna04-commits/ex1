# VIBE project

This is a static Hebrew/RTL personal styling app, published from `main` to GitHub Pages. Keep the app free of AI and backend services unless the user explicitly changes that requirement.

## Delivery workflow

The user requested that changes we make be pushed automatically. After finishing each requested change, run relevant checks, commit the task's files, push to `origin/main`, and verify the Pages deployment. If the user requests local-only work or a different branch, follow that instruction instead. Do not force-push or include unrelated user changes.

## Personal photos

Process personal photos locally in the browser. Do not upload photos or include them in Git, favorites, telemetry, or server storage. Explain manual photo-editing limitations in the interface. Keep keyboard/button alternatives for any dragging controls.
